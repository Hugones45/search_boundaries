Welcome! I'm really glad you're here.

This is one of several applications in my portfolio, built with a simple goal: to share information, my work, and my genuine passion for maps.

With City Boundaries, exploring the world is as easy as typing a city's name. Wait a moment, and you'll be taken straight to its location, see its territorial boundaries, and get real-time weather conditions for that spot.

It's built with APIs from Esri, OpenWeather, and Geoapify a small stack I truly enjoy working with.

One honest note: if a search fails, it's probably because we've hit an API request limit. The app currently relies on free APIs, which come with relatively low call limits.
